# webTasteLab
Site de recettes de cuisine — Projet Web L2 Informatique, ULCO.
TasteLab permet de consulter et rechercher des recettes par titre, ingrédient ou tag.
Un mode administrateur permet d'ajouter, modifier et supprimer les recettes, ingrédients et tags.
